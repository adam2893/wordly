# Connections category bank. tools/build_connections.py builds daily puzzles
# from these: one category per difficulty, four words from each, and only
# puzzles with exactly one way to sort the 16 words are kept.
#
# Format:  difficulty | category name | rule | SHOWN WORDS | ALSO FITS
#   difficulty  0 yellow (straightforward) .. 3 purple (trickiest)
#   rule        "-" for none, or one the builder also uses to spot words from
#               other categories that would fit this one (to reject puzzles
#               with two answers):
#                 start:CAR CAB    starts with one of these (and is longer)
#                 end:ONE TEN      ends with one of these (and is longer)
#                 contains:RED     contains one of these (and is longer)
#                 before:BALL      WORD+BALL is a dictionary word
#                 after:FIRE       FIRE+WORD is a dictionary word
#                 palindrome       reads the same backwards
#                 anagram:STEAL    rearranges these letters
#   SHOWN WORDS puzzle words are picked from these
#   ALSO FITS   optional; never shown, but counted when checking whether a
#               word from another category could belong here too
#
# Be generous with ALSO FITS: the builder can only catch a word that fits
# two categories if both lines (or rules) include it.
#
# Editing this file only affects puzzles that haven't been generated yet;
# existing ones in public/words-connections.js keep their place.
